# BeadGrid 设备与图纸参考

本目录保存产品实现所依据的实物照片、官方设备规格、在线图纸入口和项目自制的空白模板。原始照片保持原文件名与内容不变。

## 实现结论

1. “设备”由豆径、钉距、单板格数、是否可连接四个参数描述，品牌名称只是预设入口。
2. 当前照片中的大方板无法可靠识别品牌，应用默认使用“通用 Midi 29 × 29 / 5 mm”，并要求用 50 mm 校准尺验证打印比例。
3. 施工图默认在每个有豆格内写实际色号；也可切换为简写符号。
4. 分板图必须显示顶部、底部、左侧、右侧的全局坐标，避免跨板时重新从 1 计数。
5. 热压温度取决于豆子品牌、尺寸、底板/纸张和设备。未经设备说明书确认，不把照片显示值或某个网络温度写成通用预设。

## 目录结构

- `device-profiles.json`：实现使用的设备预设及官方证据链接。
- `equipment-notes.md`：实物设备工作流与安全边界。
- `templates/online-patterns.md`：可从官方站点获取的图纸入口。
- `templates/blank-*.svg`：项目自制的 1:1 空白底板模板，可直接打印或继续编辑。

所有毫米尺寸均指“钉中心节距 × 格数”得到的拼图区理论尺寸，不等于塑料底板外壳尺寸。打印机可能缩放页面，使用前必须检查模板上的 50 mm 校准尺。
